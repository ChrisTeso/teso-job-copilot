# Security and privacy boundary

This public showcase uses a static, hand-authored synthetic dataset. It contains no application tracker, resume, email address, recruiter name, job URL, authentication flow, analytics, cookie access, local database, or network request.

The production-style boundary is intentional: a real job-search system should keep candidate records and outreach history behind authentication, enforce least privilege, and export only aggregate or redacted views.

Please report vulnerabilities through GitHub Security Advisories. Do not include personal job-search information in an issue.
